# XN Resource Editor 汉化版 (zh_CN)

> 把经典的资源修改工具 XN Resource Editor 汉化成简体中文，界面全中文，操作更顺手。

## 📖 简介

XN Resource Editor 是一款轻量级、功能强大的 Windows 资源查看与修改工具。原版虽然功能强大，但全英文界面对国内用户不太友好。

本项目致力于将 XN Resource Editor 的菜单、对话框、提示信息及工具栏全部翻译为简体中文，保留了原汁原味的操作逻辑，同时降低了使用门槛。

## ✨ 汉化内容

本次汉化覆盖了软件界面的每一个角落：

- **主菜单栏**：文件、编辑、视图、资源、帮助等一级菜单。
- **工具栏按钮**：新建、打开、保存、添加资源等常用图标提示。
- **右键菜单**：资源树列表中的右键操作选项。
- **对话框**：属性设置、导入/导出资源时的弹窗提示。
- **状态栏与提示**：鼠标悬停时的 Hint 提示信息。

## 🚀 使用方法

1. **下载**：点击右侧 `Releases` 下载最新版本的压缩包。
2. **备份**：建议先备份原版的 `XN Resource Editor.exe`。
3. **替换**：将汉化后的 exe 文件放入原程序目录，直接覆盖即可（或者单独运行）。
4. **运行**：双击运行，享受全中文界面！

## ⚠️ 注意事项

- 本汉化基于 XN Resource Editor 的特定版本制作，请确认版本匹配，否则可能导致乱码或无法运行。
- 部分系统可能需要安装中文字体支持（通常 Win10/11 无需担心）。
- 修改 PE 文件存在风险，请在操作前务必备份原文件！
